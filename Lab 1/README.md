## 1. Төслийн тухай ба Хийсэн ажлууд (Overview & Progress)
Энэхүү лабораторийн ажлаар Playwright хэрэгслийг ашиглан UI автомат тестийн орчинг тохируулж, веб хөтчийн ажиллагааг автоматжуулсан функционал тестүүдийг бичиж гүйцэтгэлээ.

**Хийгдсэн үндсэн ажлууд:**
- Node.js болон TypeScript орчинд Playwright төслийг шинээр үүсгэн тохируулсан.
- `https://www.saucedemo.com` демо веб сайт дээр ажиллах 3 бие даасан тестийн скриптийг `tests/mytest.spec.ts` файлд бичсэн.
- **Тест 1:** Амжилттай нэвтрэх болон залуурчлалыг шалгах (`getByText`, `toHaveURL`).
- **Тест 2:** Сөрөг тест буюу буруу нууц үгээр нэвтрэх үед алдааны мессеж гарч буйг шалгах (`getByRole`).
- **Тест 3:** Нэвтэрсний дараах үйлдэл буюу бараа сагслах ажиллагааг шалгах (`getByLabel`).
- Орчин үеийн locator-уудыг ашиглаж, тест бүрийн төгсгөлд Logout хийх зарчмыг мөрдсөн.
- `npx playwright test` болон `npx playwright show-report` командууд дээр тестийн үр дүнг шалгаж, бичлэг (video) ба Trace тохиргоог идэвхжүүлсэн.

## 2. Playwright ба Selenium-ийн харьцуулалт ба Ажиглалт

Миний бие энэхүү лабораторийн ажлыг хийж гүйцэтгэх явцдаа Playwright болон Selenium хэрэгслүүдийн талаар дараах ажиглалтыг хийлээ. Selenium нь UI автоматжуулалтын анхдагч хэрэгсэл хэдий ч тест ажиллах бүрд тусдаа драйвер шаарддаг бөгөөд элементийг хүлээх логикийг гараар бичих шаардлагатай байдаг. Харин Playwright нь браузеруудыг багцаар нь хурдан суулгадаг бөгөөд элемент бэлэн болтол автоматаар хүлээдэг функцтэй тул тогтворгүй тест үүсэхээс сэргийлдэг. Мөн Selenium-тэй харьцуулахад Playwright-ийн Codegen болон Trace Viewer зэрэг хэрэгслүүд нь алдааг дебаг хийх, тест бичих хурдыг асар их нэмэгдүүлдэг давуу талтай. Нэмж дурдахад Playwright-ийн `getByRole`, `getByText` гэх мэт орчин үеийн locator-ууд нь кодын далд бүтцээс хамааралгүй, хэрэглэгчийн харах UI дээр тулгуурладаг тул тестүүд нь илүү тогтвортой ажилладаг. Иймээс Playwright нь орчин үеийн веб аппликейшнийг хурдан, найдвартай тестлэхэд Selenium-ээс хавьгүй давуу талтай хэрэгсэл гэж дүгнэж байна.
